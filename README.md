# T&C TIME MACHINE — Phase 1

A zero-cost-target, static prototype designed to become a shared platform for T&C websites.

## Included in Phase 1
- Responsive Apple-inspired interface
- Light/dark appearance toggle
- Universal subject search
- Starter category browsing
- Search suggestions while typing
- Past / Present / Future perspective tabs
- Expandable architecture-ready content structure
- Clear distinction between verified context, current context, forecasts and hypothetical scenarios
- No paid service or API dependency

## Run locally
Open `index.html` in a modern browser.

## Publish with GitHub Pages
1. Create a new GitHub repository, for example `T-C-TIME-MACHINE`.
2. Upload all files and folders from this project.
3. Open repository Settings → Pages.
4. Choose deploy from branch, select `main` and `/ (root)`, then Save.
5. GitHub Pages will provide the website address.

## Important Phase 1 limitation
This is a frontend prototype with a small set of starter examples. It is not yet a live research engine and does not claim to know current events or the future. Phase 2 will add source connectors, dates, citations and real data retrieval.

## Integration plan
Once deployed, other T&C websites can embed the published URL using an iframe. A reusable JavaScript integration interface and API-compatible data contract will be added in a later phase.

## Cost
The project code has no paid dependencies. GitHub Pages is used as the intended free static hosting option, subject to GitHub's current terms and limits. Third-party data providers may have their own usage limits and terms.
